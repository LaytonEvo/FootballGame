# Fantasy Five (working title)

Handoff package for building the closed-test MVP of a 5-a-side Premier League fantasy card game.

Start a new repo with these files, open it in Claude Code and say:

> Read CLAUDE.md and start Phase 0.

- `CLAUDE.md`: build brief, rules, stack, phases and acceptance criteria
- `docs/SPEC.md`: game design spec
- `docs/DESIGN.md`: visual direction and screen list
- `design/`: tokens and mockup source
- `config/`: scoring and economy values (data, not code)
- `tools/sim/`: points-table simulator and 2025/26 baseline results
