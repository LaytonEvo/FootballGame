# Staff runbook (admin console)

Run: `pnpm --filter @ff/admin dev` (http://localhost:5174), pointing at the API with `VITE_API_URL`.
Staff sign in with a token from `STAFF_TOKENS` on the API (`name:token,name2:token2`, tokens ≥ 16 chars).
Every action is written to the audit log with the staff name (Audit tab).

## Every edge case in docs/SPEC.md

| Situation (SPEC)                            | What happens                                                                                                        | Staff action                                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Starter plays 0 minutes                     | Automatic: sub comes in with its own actions                                                                        | None                                                                                                                                                         |
| Starter and sub both 0 minutes              | Automatic: slot scores 0, bold voided                                                                               | None                                                                                                                                                         |
| Blank gameweek for a club                   | Automatic (0 minutes, sub rule)                                                                                     | None                                                                                                                                                         |
| Double gameweek                             | Automatic: combined stats                                                                                           | None                                                                                                                                                         |
| Match postponed or abandoned                | Automatic when the feed reports it                                                                                  | If the feed is wrong or late: **Gameweeks & matches → Matches → Postponed** or **Void** (with a reason). Re-scores immediately. Blocked after finalisation   |
| Stats revised after the match               | Automatic until 09:00 finalisation; later revisions are logged (`stat_revisions.applied = false`) and never applied | None. To check a complaint: **Users & ledger → Scoring breakdown** shows every line ("Assist landed: 15 × 1.1 rarity × 2 bold = 33")                         |
| Player sent off                             | Automatic (stats before the red card)                                                                               | None                                                                                                                                                         |
| Leaderboard tie                             | Automatic (most landed, then fewest picked)                                                                         | None                                                                                                                                                         |
| Player moves to another league club         | Card follows the player from the next deadline                                                                      | Normally from the feed. Manual: **Players & transfers → search → choose club → Transfer**                                                                    |
| Player leaves the league (abroad, loan out) | Card inactive, out of the five (squad auto-filled), free same-rarity swap pack, one grouped notification            | **Leaves league**                                                                                                                                            |
| Player returns to the league                | Card reactivates; owner keeps the swap-pack card                                                                    | Choose club → **Returns**                                                                                                                                    |
| Player retires                              | As leaving                                                                                                          | **Retires**                                                                                                                                                  |
| Club relegated (season end)                 | All its cards inactive, one swap pack per card                                                                      | **Clubs → Relegate**                                                                                                                                         |
| Club promoted                               | Players join the pack pool                                                                                          | **Clubs → Promote**                                                                                                                                          |
| Transfer-window notifications               | Grouped per user per batch                                                                                          | None                                                                                                                                                         |
| Card rating wrong                           | —                                                                                                                   | **Players → rating** (optionally re-rate existing cards) or **Users → Cards → rating**                                                                       |
| Points table or prices change               | Data, not code                                                                                                      | **Points & economy → Edit as new → change `version` → Upload (validated) → Activate**. Locked gameweeks keep their scoring version; prices apply immediately |
| Pack complaint ("odds feel wrong")          | Every opening logged with type, odds version, seed and result                                                       | **Pack log** (filter by user). `planPack` reproduces a draw from the seed                                                                                    |
| Coins complaint                             | Ledger is append-only; balance = sum                                                                                | **Users & ledger** shows balance, ledger and "reconciles"; **Adjust Coins** adds a correcting row (reason required)                                          |
| Account deletion request (UK GDPR)          | —                                                                                                                   | **Users → Delete account** anonymises, ends sessions, leaves leagues                                                                                         |
| Gameweek scores look stale during matches   | Worker re-scores every minute                                                                                       | **Gameweeks → Re-score** (before finalisation only)                                                                                                          |

Card gifting does not exist in the MVP, so the "no gifting under 30 days" rule has nothing to enforce yet.
